# Doa Puja Yesus — The Jesus Prayer Across Rites

Aplikasi web doa kontemplatif digital untuk mendaraskan **Doa Puja Yesus (Jesus Prayer)** dari berbagai tradisi Kristen: Ortodoks Bizantin, Katolik Roma, Siriak, Koptik, dan lainnya.

🌐 **Demo:** https://prayer-steel-kappa.vercel.app

## Fitur

- **Pilih Ritus & Bahasa** — Yunani, Latin, Aramaik, Koptik, Slavonik, Indonesia, Jawa
- **Hitungan Doa Fleksibel** — 33, 50, 100, atau 200 repetisi
- **Ikon Meditatif** — Visual berganti secara progresif dari 20 peristiwa dalam kehidupan Yesus
- **Kutipan Bapa Gereja** — 40+ kutipan rohani sebagai penutup doa
- **Mobile-Friendly** — Responsif, layar penuh, dukungan safe-area untuk HP modern

## Cara Pakai

1. Buka halaman web
2. Pilih ritus/bahasa doa
3. Pilih jumlah hitungan (33/50/100/200)
4. Tekan **Mulai Doa**
5. Tap area bawah layar setiap selesai mendaraskan doa
6. Selesai — baca kutipan penutup, lalu ulangi atau kembali

## Development

```bash
# Tidak perlu install — cukup buka index.html di browser
# Untuk download gambar (jika perlu):
npm run download-images
```

## Teknologi

- HTML + CSS + JavaScript murni (vanilla)
- Font: Cinzel, EB Garamond (Google Fonts)
- Ikon: reproduksi domain publik dari tradisi ikonografi Kristen

## Lisensi

Hak cipta pada aset ikon dan kutipan masing-masing milik pemiliknya.
Kode sumber terbuka — silakan digunakan untuk tujuan rohani dan edukasi.
